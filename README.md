# Arun Kumar C — Portfolio

A responsive blue/white portfolio inspired by the supplied reference website.

## Run
Open `index.html` directly, or serve the folder with any static server.

## Deploy to Vercel
Import this folder/repository into Vercel. No build command is required.

## Hero visual
The hero currently shows a terminal-style panel (`.photo-placeholder` in `index.html`, styled in `style.css` under `.term-bar` / `.term-body`) instead of a photo — it reads as backend/dev-focused at a glance, which is intentional. If you'd rather use a headshot, replace the `.photo-placeholder` contents with:
`<img src="profile.jpg" alt="Arun Kumar C">`
and place your `profile.jpg` beside `index.html`. You'll also want to override `.photo-placeholder`'s background/padding in `style.css` since those rules are written for the terminal panel.

## Content
Portfolio content is based on the supplied resume.
